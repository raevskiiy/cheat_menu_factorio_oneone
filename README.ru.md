# Cheat Menu (Чит-меню) для Factorio 2.1 beta

[English](README.md) | **Русский**

> **Эта ветка рассчитана на Factorio 2.1 (сейчас в бета-версии).**
> Для Factorio **1.1** используйте [ветку `main`](../../tree/main).
> Стабильная версия 2.0 этой веткой **не поддерживается**, потому что в моде указано `factorio_version: 2.1`.

Простое чит-меню с аккуратным окном прямо в игре. Меняйте параметры персонажа, включайте читы и запускайте частые действия без ввода консольных команд. Поддерживает стили кнопок [GUI Unifier](https://mods.factorio.com/mod/GUI_Unifyer).

## Возможности

**Параметры персонажа** (ползунки)

| Ползунок | Что делает | Диапазон |
|---|---|---|
| Скорость крафта | Бонус к скорости ручного крафта | до x101 |
| Скорость бега | Бонус к скорости бега | до x11 |
| Скорость добычи | Бонус к скорости ручной добычи | до x101 |
| Дальность действий | Дальность строительства, добычи, выброса и подбора предметов | от +0 до +320 |
| Макс. здоровье | Дополнительное максимальное здоровье | до +10000 |
| Слоты инвентаря | Дополнительные слоты инвентаря | до +200 |

**Переключатели**

- Бессмертие
- Ванильный чит-режим (бесплатный и мгновенный крафт)
- Всегда день на текущей поверхности

**Действия**

- Полное лечение
- Изучить все технологии
- Открыть все рецепты
- Открыть карту (500 клеток вокруг вас)
- Убрать загрязнение на текущей поверхности
- Сбросить все параметры

## Как пользоваться

- Нажмите кнопку **Cheat Menu** в левой верхней панели кнопок модов, или
- нажмите **Ctrl + Shift + C** (меняется в Настройки → Управление).

Настройки сохраняются вместе с сохранением игры и заново применяются после респавна.

## Мультиплеер

По умолчанию меню видят и используют только **админы**. Это меняется настройкой карты **«Чит-меню: только для админов»** (Настройки → Настройки модов → Карта). В одиночной игре вы всегда админ. Все игроки на сервере 2.1 должны использовать одну и ту же версию Factorio.

## Совместимость с GUI Unifier

У GUI Unifier нет публичного API для других модов: он перекрашивает кнопки из своего встроенного списка поддерживаемых модов. Поэтому Cheat Menu ставит свою кнопку в стандартную панель кнопок модов (`mod_gui`) и берёт стиль кнопок, выбранный в настройках GUI Unifier, в том числе стиль «нажата», пока окно открыто. Если GUI Unifier не установлен, используется обычный стиль кнопок модов. GUI Unifier — необязательная зависимость.

## Установка

1. Включите бета-версию Factorio 2.1 (Steam: правый клик по Factorio → Свойства → Беты; или скачайте экспериментальную сборку на factorio.com).
2. Скачайте `cheat_menu_<версия>.zip` на странице [Releases](../../releases) (релиз с пометкой 2.1).
3. Положите zip (не распаковывая) в папку `mods` Factorio:
   - Windows: `%appdata%\Factorio\mods`
   - Linux: `~/.factorio/mods`
   - macOS: `~/Library/Application Support/factorio/mods`
4. Запустите игру и убедитесь, что **Cheat Menu** включён в меню модов.

## Что изменилось по сравнению с версией для 1.1

- `global` заменён на `storage`.
- Кнопка закрытия использует спрайты из 2.x (`utility/close`).
- «Полное лечение» использует `LuaEntity.max_health` и больше не зависит от значения прототипа.
- Значения ползунков привязываются к шагу в коде, а не через флаги ползунка.
- `info.json` нацелен на Factorio 2.1 (`base >= 2.1.0`).

## Примечания

- Factorio 2.1 в бете, и API для модов ещё может меняться. Если обновление сломает мод, создайте issue.
- Использование читов может отключить достижения.
- При удалении мода применённые к персонажу бонусы автоматически не снимаются. Перед удалением нажмите **«Сбросить всё»** в меню.
- Мод пока не запускался в игре на каждой бета-сборке 2.1, он сверен с документацией API 2.1.
